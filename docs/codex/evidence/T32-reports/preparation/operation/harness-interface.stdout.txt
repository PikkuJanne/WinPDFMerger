Operate an exact final-R ZIP on Windows; development-only, no installation.
T32 derivative of the frozen T29 harness. Legacy candidate field/CLI names and
original synthetic fault tokens stay stable; the accepted release source is
fixed. All application code comes from a hash-verified ZIP. Python, fixture
generation and independent PDF readers belong only to this test driver. Each
scenario uses a fresh extraction and an unrelated working directory. The GS
failure scenario uses a disclosed child-only resource configuration fault in
the genuine engine.
